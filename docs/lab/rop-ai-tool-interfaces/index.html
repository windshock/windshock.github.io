What this comparison shows

Observed end-to-end Hinoki usage in three synthetic labs: direct exploit authoring versus an implementation that delegates selected functions to specialized tools. It does not claim an identical savings ratio for every request.

Exact JSON summary adapters exist, but should not be confused with model tool calls proven in the A/B sessions. Current ROP chain inputs remain explicitly chosen by the harness.
